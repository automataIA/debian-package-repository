This is a signed APT repository (@CODENAME@ / @COMPONENTS@, @ARCHS@) served via GitHub Pages. It is built by GitHub Actions from the packages published in the Releases of each project.

Quick setup

wget -O- @PAGES_URL@@KEYRING_FILE@ | sudo tee /usr/share/keyrings/@KEYRING_FILE@ >/dev/null
sudo tee /etc/apt/sources.list.d/automata.sources <<'EOF'
Types: deb
URIs: @PAGES_URL@
Suites: @SUITE@
Components: @COMPONENTS@
Architectures: @ARCHS@
Signed-By: /usr/share/keyrings/@KEYRING_FILE@
EOF
sudo apt update

Easier: install the keyring package

wget @PAGES_URL@pool/main/a/@KEYRING_PACKAGE@/@KEYRING_PACKAGE@_1.0.0-1_all.deb
sudo apt install ./@KEYRING_PACKAGE@_1.0.0-1_all.deb
sudo apt update

Then install any package normally, e.g. sudo apt install search2md.

Repository contents

  • dists/@SUITE@/InRelease (signed metadata)
  • @KEYRING_FILE@ (public signing key)
  • automata.sources (Deb822 sources file)
  • pool/ (the .deb files)

Suite @CODENAME@ is a rolling suite for standalone applications; it is not tied to a specific distribution release. Fingerprint: @KEYRING_FPR@
