01 / Install

Add the archive once.

The recommended setup uses the archive keyring package. It installs both the public key and the Deb822 source definition, keeping trust scoped to this repository.

  1. Install the repository keyring

    wget @PAGES_URL@pool/main/a/@KEYRING_PACKAGE@/@KEYRING_PACKAGE@_1.0.0-1_all.deb
sudo apt install ./@KEYRING_PACKAGE@_1.0.0-1_all.deb
sudo apt update

  2. Install a package

    sudo apt install search2md

    Replace search2md with the package you need. Future updates are delivered through the normal APT workflow.

Manual setup without the keyring package

Keys added manually belong in /etc/apt/keyrings. The source remains explicitly bound to this repository key.

sudo install -d -m 0755 /etc/apt/keyrings
wget -O /tmp/automata-archive-keyring.gpg @PAGES_URL@@KEYRING_FILE@
sudo install -m 0644 /tmp/automata-archive-keyring.gpg /etc/apt/keyrings/
rm /tmp/automata-archive-keyring.gpg
sudo tee /etc/apt/sources.list.d/automata.sources >/dev/null <<'EOF'
Types: deb
URIs: @PAGES_URL@
Suites: @SUITE@
Components: @COMPONENTS@
Architectures: @ARCHS@
Signed-By: /etc/apt/keyrings/automata-archive-keyring.gpg
EOF
sudo apt update
